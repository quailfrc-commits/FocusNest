# FocusNest 公開版本說明

`v0.7-public` 是本次競賽公開版的發行標籤，用來表示已移除開發者金鑰、私人區網位址、展示帳號備份與成果照片的可公開版本。

Android 專案目前沿用原生外殼的 `versionName 1.0` 與 `versionCode 1`。這兩個欄位是 Android 安裝套件的內部版號，與 GitHub Release 的競賽公開版標籤用途不同，因此不應解讀為兩個互相矛盾的產品版本。

公開 APK 以清理後的前端內容重新封裝並簽署，完成敏感資料掃描後，也已在實體裝置驗證安裝、登入同步、Gemini 任務拆解、橫放專注與成果回顧。SHA-256 校驗檔與 APK 一同放在 Release，供下載後核對檔案完整性。
