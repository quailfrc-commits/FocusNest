# FocusNest 技術測試紀錄空白範本

本文件是待執行測試的空白範本，不是 FocusNest 的完成測試報告。「待測」與「待填」代表尚未填入結果；所有數字都必須來自實際操作，不得使用推估值或展示資料代替。

## 測試環境

- 受測版本：填寫實際測試的 Release 標籤或提交版本
- Android 裝置：Redmi Note 10 Pro
- 電腦端：Windows、Web 與 Electron 桌面版
- 網路：手機與電腦位於同一區域網路
- 後端：Node.js、Express、PostgreSQL
- AI：Google Gemini API

## 建議保留的證據

- Gemini 真實回傳的模型名稱與時間
- 後端開始、拿起、放回與完成事件畫面
- 手機與電腦同步顯示相同倒數及警告的畫面
- 每日成果照在不同裝置同步顯示的畫面

## 結果寫法

完成測試後，以「成功次數／總次數」呈現，例如 `10/10`；同步延遲可另外記錄平均值與最大值。若出現失敗，應保留原因與修正結果，不只列成功案例。
